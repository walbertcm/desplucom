# DESPLUCOMP

O **DESPLUCOMP** é uma solução computacional desenvolvida para apoiar a aplicação, o registro e o acompanhamento de atividades de Pensamento Computacional na Educação Básica.

A solução integra um aplicativo móvel, planilhas eletrônicas on-line e um módulo de gestão docente, permitindo organizar atividades, registrar os resultados dos estudantes e acompanhar o desempenho de forma integrada.

## Componentes

O DESPLUCOMP é composto por:

* **Aplicativo móvel:** utilizado pelos estudantes para realizar as atividades;
* **Planilhas on-line:** utilizadas para armazenar questões, alternativas e resultados;
* **Módulo docente:** desenvolvido em Python para consulta, processamento e acompanhamento dos resultados.

## Principais funcionalidades

* aplicação de atividades de Pensamento Computacional;
* carregamento das questões a partir de planilhas on-line;
* atualização das questões sem necessidade de modificar o código do aplicativo;
* registro dos resultados dos estudantes;
* acompanhamento individual e geral da turma;
* classificação dos resultados;
* geração de informações de apoio ao acompanhamento docente.

## Tecnologias utilizadas

* MIT App Inventor
* Python
* Google Sheets
* Google Apps Script

## Contexto

O DESPLUCOMP foi desenvolvido para apoiar atividades relacionadas ao Pensamento Computacional na Educação Básica, considerando habilidades previstas na BNCC Computação.
